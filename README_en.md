# Workshop: _Creating a serverless Telegram bot_

At this meeting, we will step by step create a serverless Telegram-bot and have some hands-on experience with Yandex Cloud Functions, Yandex Managed Service for YDB, and other cloud services.

We will be using these technologies and services :

* IntelliJ IDEA Community Edition
* Yandex Cloud CLI
* Terraform
* Yandex API Gateway
* Yandex Managed Service for YDB
* Yandex Cloud Functions
* Yandex Object Storage
* Yandex Lockbox
* Yandex Cloud Logging

We will be working in the terminal, console, and IDE.

Our workflow is clearly divided into steps. Before each step, you will see visual aids and its explained walkthrough; then, you will be able to complete the step on your own.

For each step, there is a respective folder in [./steps](./steps).
In such a folder, there is a `README.md` file with detailed guidance and command sections. Copy those sections by clicking them, and then paste the relevant one into your terminal.

Now it is time to [set up your environment](./steps/00-init/README.md): this step is crucial, as otherwise you will not be able to fully participate in the workshop.

P.S. Before the workshop starts, this guide will be updated and all steps will be added.
For your convenience, make sure to clone a repository, and may `git clone` be with you.
